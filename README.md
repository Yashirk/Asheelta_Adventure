# Nichel: The Quest for Asheelta ❤️

A mobile-ready, pixel-style platform adventure built with HTML, CSS, and JavaScript Canvas. No build tools or game engine install are required.

## Run it locally

1. Extract the ZIP.
2. Open `index.html` in a modern browser.
3. Click **Start the quest**. For best results, use VS Code with the Live Server extension.

## Controls

- Move: `A` / `D` or `←` / `→`
- Jump: `W`, `↑`, or `Space`
- Quick attack: `J` or `X`
- Heavy attack: `K`
- Dash: `Shift`
- Mobile: use the on-screen left/right, attack, heavy attack, dash, and jump buttons.

## What is in this upgraded prototype?

- Four themed regions: Green Kingdom, Mushroom Woods, Shadow Pass, and Dragon Valley
- Different enemy types, tougher armored enemies, hit feedback, and a dragon that fires projectiles
- Quick and heavy attacks, a dash with brief invulnerability, and weapon-specific damage/range
- Hidden treasure chests that unlock the Wooden Sword, Steel Blade, and Roseblade
- Roses, score, hearts, checkpoints, and the final romantic message
- A secret-code terminal

## Secret codes

Enter these in the Secret Code Terminal (codes are case-insensitive):

- `ROSEPOWER` — restore all hearts, collect the roses, and gain bonus score
- `SWORDUP` — unlock the Roseblade
- `GODMODE` — toggle damage immunity
- `BIGJUMP` — toggle extra-high jumps
- `COINRAIN` — gain 1,000 score

## Publish on GitHub Pages

1. Create a repository, e.g. `nichel-quest-for-asheelta`.
2. Upload the files in this folder to the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/(root)`, then save.
5. Open the published URL on your phone.

On Android, open the URL in Chrome and use the browser menu to choose **Add to Home screen** or **Install app** if available. APK packaging can be a later step using Capacitor.
